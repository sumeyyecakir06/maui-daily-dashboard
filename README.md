## Core Features
* **Authentication System:** Secure Login page with access control leading to the main Home Page.
* **Real-Time Weather & Exchange Rates:** Fetches and displays live weather conditions and up-to-date currency exchange rates.
* **News Feed & Details (Master-Detail):** Browse the latest headlines with a master list view and navigate to a dedicated details page for full articles.
* **To-Do List (Task Management):** Built-in task tracking module to add, manage, and complete daily routines.
* **Cross-Platform:** Optimized UI/UX for both mobile (Android/iOS) and desktop (Windows) environments.
  
## Tech Stack
* **Language & Framework:** C#, .NET MAUI
* **Architecture:** Multi-page routing, Master-Detail navigation
* **Data Integration:** RESTful APIs (for Weather, News, and Currency rates), JSON parsing
* **UI Markup:** XAML
